# Features

## Core Platform

- online course storefront with public catalog and course detail pages
- book catalog with free and paid resources
- student accounts with enrolled-course access
- administrator dashboard for managing the platform
- guided web installer

## Commerce and Payments

- one-time course purchases
- one-time book purchases
- Stripe checkout support
- PayPal checkout support
- manual payment request workflow with admin review
- Stripe and PayPal webhook endpoints
- access granted only after confirmed payment or approved manual review
- duplicate payment protection and payment-state reconciliation

## Content Management

- create, edit, publish, and organize courses
- lesson management and curriculum ordering
- create and manage downloadable books
- FAQ management
- editable legal and content pages
- instructor profile page management

## Design and Storefront Control

- light and dark mode support
- customizable theme colors
- configurable English font selection
- editable landing page sections
- configurable navigation menus
- modern responsive storefront and dashboard UI

## Authentication and Security

- email/password authentication
- optional Google login
- optional Google reCAPTCHA
- role-based access for admins and students

## Business and Support Tools

- finance dashboard and sales insights
- manual payment review queue
- WhatsApp contact options
- optional Tawk live chat integration
- demo-ready seeded content for fast first setup
