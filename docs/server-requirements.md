# Server Requirements

## Minimum Requirements

- PHP 8.2 or higher
- MySQL 5.7+ or MariaDB 10.3+
- Apache or Nginx

## Required PHP Extensions

- `ctype`
- `curl`
- `dom`
- `fileinfo`
- `json`
- `mbstring`
- `openssl`
- `pdo`
- `pdo_mysql`
- `tokenizer`
- `xml`

## Writable Directories

- `storage`
- `bootstrap/cache`

## Optional but Recommended Tools

- Composer
- Node.js and npm

## Notes for CodeCanyon Buyers

- The buyer package is prepared with `vendor` and `public/build` included to speed up installation.
- Composer and Node.js are still recommended if you plan to rebuild assets, install updates manually, or work on customizations later.
- Learnova is designed for MySQL or MariaDB production setups. A database server is required for normal use.
