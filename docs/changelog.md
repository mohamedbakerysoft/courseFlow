# Changelog

## 1.0.0

- Initial marketplace release of Learnova
- Guided installer with environment checks, database configuration, migrations, seeding, and administrator creation
- Course and book storefront with responsive public pages
- Student accounts with access to enrolled and purchased content
- Admin dashboard for courses, books, menus, FAQs, finance, appearance, and platform settings
- Stripe, PayPal, and manual payment workflows
- Webhook support for Stripe and PayPal
- Payment confirmation rules that grant access only after verified completion or approved manual review
- Finance insights and manual payment review tools
- Configurable landing content, menus, instructor profile, branding, and theme options
- Optional Google login, Google reCAPTCHA, WhatsApp contact options, and Tawk live chat support
- Buyer documentation prepared for CodeCanyon distribution
